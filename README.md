# One-shot Hit and Blow
## 概要
- 1/3,024 RTA
- 最初に有効な数字を入力し、判定されたらタイマースタート。
- チャンスは一回。不正解なら、ゲームがリセット。最初からです。
- 一発でターゲットの数字を当てることができたらタイマーストップ。

 ## Hit&Blowのターゲット条件
 - 0~9までで構成された4桁の数字
 - 各桁の数字が重複することはなく、全て違う数字で構成される

## 無効として判定を拒否される回答
- 数字が重複している桁がある
- 4桁未満

## タイマーの開始/終了条件
### 開始条件
- 最初に回答が判定されたとき
### 終了条件
- 回答した数字とターゲットの数字が一致したとき

## その他
- 開始後、「GIVE UP」ボタンを押すことで強制終了できます。
- 強制終了またはクリア後、「NEW GAME」ボタンを押すと最初の状態に戻すことができます。
